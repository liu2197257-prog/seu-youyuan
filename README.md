# 六朝松 · 校史解谜游戏

一款关于东南大学四牌楼校史的二维点击解谜游戏。玩家带着一枚「年轮珀」穿过四个历史时期，
替留在六朝松里的记忆投影，找回他一生都没看懂的位置。

序章（当代）→ 第一章 1933 → 第二章 1959 → 第三章 1988 → 第四章 2002 → 尾声。

## 怎么玩

**双击 `启动游戏.cmd`**（或直接打开 `dist/index.html`）即可开始。

- 无需安装、无需构建、无需联网，不依赖任何 CDN、npm 包或字体文件。
- 手机横屏优先，桌面浏览器同样可玩。
- 刷新即从头开始，没有存档。

## 操作

| 场景 | 操作 |
|---|---|
| 俯视跑图 | 虚拟摇杆（手机）／ WASD 或方向键（桌面）；靠近建筑后点「查看」或按 E |
| 正面 2D 近景 | 点触拾取；选中物品栏道具后再点目标；拖动／旋转完成机关 |
| 年轮珀 | 右上「年轮珀」按钮：查看已刻年轮、主动请求三级提示 |
| 声音 | 默认关闭；右上角按钮开启。所有声音线索都有视觉等效表现，静音也能通关 |

## 测试

```sh
node --test                                        # 纯逻辑 + 渲染 + 约束检查
node tests/browser.cjs                             # 真实浏览器全篇通关（需要 Edge/Chrome）
```

浏览器回归会依次验证：启动、序章演出、三幕刻轮与接合门槛、第三章记忆槽、
三件物证与逐件投射、尾声字幕、25 个场景渲染、六种横屏尺寸无溢出、
热区尺寸与不重叠、摇杆归零、动画期间返回保护、零外部网络请求与零控制台错误。

## 设计依据

全部内容以 `../设计/交接文档.md` 为唯一权威输入。§10 的 8 个待定项采用其建议默认值：

- 美术：全程序化 SVG（预留 `backgroundImage` 本地背景槽位）
- 第二章齿轮：指示叶片纹 / 传动三轮纹
- 第二章树前台词：「楼里还有没做完的事。」「去看看吧。」
- 三幕文学名称留空，只用年代标识
- 纯 JS、无构建
- 无存档
- 声音默认关闭
- 从零实现

真实建筑与校史事件遵循文档；守忆者、年轮珀、周老师、沈立等均为虚构。
吴健雄纪念馆只承担真实层，不含任何虚构人物或物证。
