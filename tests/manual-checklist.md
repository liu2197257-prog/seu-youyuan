# 全篇人工验收清单

以 `设计/交接文档.md` 为唯一权威输入。每次重大修改后，在静音与开启声音两种模式下各至少完成一次全篇通关。

## 启动与工程

- [ ] 断网后双击 `启动游戏.cmd`，可从序章玩到尾声；直接打开 `dist/index.html` 结果相同。
- [ ] 无构建、无 CDN、无字体/图片/音频外部请求；开发者工具 Network 无网络依赖。
- [ ] 刷新即从头开始，没有存档读写。
- [ ] 手机横屏及桌面键鼠均可完成所有操作；竖屏有可点的横屏入口。
- [ ] 手机开启方向锁定后，点入口仍可进入横屏（方向锁定或画布旋转兜底），横过来即正。
- [ ] 动画中返回、关闭弹层、切换场景不会出现延迟回调报错或状态跳跃。

## 28 条硬约束

### 叙事

- [ ] 1. 信始终由玩家持有，守忆者从未看到；结尾由玩家主动放回相机包后侧夹层。
- [ ] 2. 守忆者只在六朝松正面 2D 场景出现，俯视地图和建筑内部均无守忆者。
- [ ] 3. 吴健雄纪念馆只有真实层展陈，无虚构人物、物证、齿轮或任务入口。
- [ ] 4. 真实建筑与校史变化未被玩家改写；投射表达“留下的东西被人用了”。
- [ ] 5. 无安慰台词，无“我原谅你／别难过／没关系”等文本。
- [ ] 6. 无主题总结、无大段校史讲授；真相从物件与操作链条显现。
- [ ] 7. “最后一排”暗线在图书馆、大礼堂、2002 典礼册中连续出现。
- [ ] 8. “低—高—中—低”贯穿 1933、1959，并在回忆/刻轮中保留。
- [ ] 9. 植松者不在场，不标种植年份；玩家只是见证并照看幼苗。
- [ ] 10. 孟芳图书馆与动力楼争议年份不作为任何谜题答案。

### 机制

- [ ] 11. 全程仅一枚年轮珀，初始已有三层空白结构环，之后最多刻三圈。
- [ ] 12. 1933、1959、1988 均须回树接合才能进入下一时代；刻轮本身不跳幕。
- [ ] 13. 缺少任一齿轮不能刻轮；体育馆提前安装的单齿轮离开后保留。
- [ ] 14. 普通道具不跨时代；图样、声音与记忆由年轮珀保存。
- [ ] 15. 关闭声音仍可靠图形高亮、振动和文字完成全部声音谜题。
- [ ] 16. 三级提示只能由玩家主动点击年轮珀触发，不自动弹出。
- [ ] 17. 主线单向推进，不能返回旧时代地图。
- [ ] 18. 无分支、无多结局、无额外重要选择。

### 视觉

- [ ] 19. 裂痕从头到尾保留；树脂只填一小段，新芽从裂口内部长出。
- [ ] 20. 真正饱和的绿只用于结局新芽；其余时代绿色克制低饱和。
- [ ] 21. 守忆者无清晰五官，第三章五段第一人称回忆不出现他的脸。
- [ ] 22. 年轮珀无明显白色高光，右上缺口、三层环、炭黑树心清楚可辨。
- [ ] 23. 无写实照片、三维渲染和复杂渐变；保持深褐粗轮廓、低饱和平涂、轻纸感。

### 工程与操作

- [ ] 24. 纯静态、双击即玩、离线运行。
- [ ] 25. 手机横屏优先，桌面兼容；安全区不会遮挡关键操作。
- [ ] 26. 所有实际可点热区至少 44×44 CSS px，热区无重叠，尤其树脂/裂口和木槌/发声片。
- [ ] 27. 状态机与谜题判定不依赖 DOM，可单独运行 Node 测试。
- [ ] 28. 所有动画、计时器、拖动、声音在离场时安全取消或完成，过期回调无效。

## 全篇重点路径

- [ ] 序章演出顺序：看见守忆者→转头→伸手→未碰树树先断→黑影震动→垂手→退出取景不可见。
- [ ] 1933 图书馆/大礼堂两种先后顺序均可通关，无跨建筑道具依赖。
- [ ] 1959 五五楼“多年后”明确可见，两核心完成后才能汇合。
- [ ] 1988 前工院未完成时校友会堂必要线索不会出现；两核心完成后只触发一次树前枢纽。
- [ ] 1988 树根装置先对入旧窗影与名册，再装齿轮。
- [ ] 2002 三物证未集齐不能结局投射；纪念馆可完全跳过。
- [ ] 三句物证反应逐件出现，最后台词后守忆者散成墨粒归树。
- [ ] 玩家最后主动放回信件，随后才进入当代同机位尾声和指定字幕。

## 设备与输入矩阵

- [ ] 手机横屏 667×375、740×360、844×390、915×412。
- [ ] 桌面 1280×720、1366×768、1920×1080。
- [ ] 摇杆释放、`pointercancel`、窗口失焦后移动归零。
- [ ] WASD/方向键、E、Escape、触屏点选、拖动和旋转均可用。
- [ ] 图纸拼合与投射拖拽容差至少 24 CSS px，旋转吸附 ±8°，无需像素级精确操作。
- [ ] 每幕接合仪式约 20–30 秒；时代转场约 5–8 秒，1988 生长量明显更大。
